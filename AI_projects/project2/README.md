# Project 2 - Image classifier

Using CIFAR-10 keras files cifar10 dataset, building a model to classify a picture. 
There are three programs. Please choose one of them in your convenience. Program descriptions are following
* Image-recognizer_large.ipynb - if your machine has enough capacity, you can run this code. This code used DenseNet121 predefined MLP model
* Image-recognizer_small.ipynb - if your machine does not have enough capacity, you can run the simpler MLP model. 
* Image-recognizer_model.ipynb - You can bring a pre-trained model.
